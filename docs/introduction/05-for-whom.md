# For Whom

**We didn’t build Drumee for a segment.**  
**We built it for a problem.**

A world where:

* your data is not truly yours  
* your workflow depends on someone else’s platform  
* and “convenience” slowly turns into dependency

If that bothers you — you’re exactly who Drumee is for.

We didn’t start with segments.

But over time, we saw the same frustration repeat itself — across very different teams.

| Segment | Primary Need | Why Drumee |
| :---- | :---- | :---- |
| Agency teams (5–25 people) | Client project isolation, IP protection | A separate external workspace per client, granular access per role |
| Legal & Healthcare firms | GDPR, HIPAA compliance, zero data leakage | Data that never leaves your infrastructure — with the self-hosted edition (coming soon) |
| SME tech teams | Replace SaaS sprawl (Notion + Drive + Slack) | One unified platform instead of several subscriptions |
| Web3 / DAO organizations | Governance integrity, censorship resistance | Fully sovereign, no platform risk — with the self-hosted edition (coming soon) |
| Developers building products | Extensible infrastructure to build on | API-first architecture; an app marketplace today, an SDK coming soon |
| Incubators & accelerators | Run many startups in one program, keep each one's data separate | One workspace per startup, shared resources for the whole cohort, granular access per role |
